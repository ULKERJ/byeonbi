Firebase 연결 정보는 입력됐어. 이제 파일 안의 ADMIN_UID를 관리자 계정의 실제 UID로 바꾸고 HTTPS로 배포해 줘.

설정 방법은 함께 제공한 README 파일에 있어.

로그인

최초 관리자 계정은 Firebase에서 아이디 admin으로 생성해야 해. 아이디만으로 접속하는 방식은 개인정보 보호에 적합하지 않아 비밀번호를 추가했어.

일별 생활 습관 · 배변 기록

입력 방식 변경: 채소·과일·운동은 오늘 실시 여부(0/1), 수면은 3~8시간을 0.1~0.5로 표현합니다. 이전 버전의 섭취 빈도 기록은 자동 변환하지 않으며 새 기준으로 다시 입력해 저장해야 합니다.

오늘의 분석은 어제 배변 유무를 먼저 확인하고, 그제의 생활 습관 → 어제 배변 유무 한 쌍으로 개인 가중치를 갱신한 뒤 오늘 입력한 생활 습관을 분류합니다. 어제 배변 기록이 없으면 분석하지 않습니다.

예: 1.2 = 1.2L · 기존 학습 데이터는 1.0/1.5/2.0L만 포함
8시간은 마지막 구간(0.5)에 포함돼요.
이 날짜의 배변 여부는 다음 날 모델을 학습할 때 사용합니다. 이 날짜의 실제 배변 여부를 오늘 분석에 미리 사용하지 않습니다.

어제의 실제 배변 기록을 사용하여 가중치를 갱신한 후, 오늘 습관에 대한 실험적 분류를 “변비 발생 가능성을 높이는/낮추는 방향”으로 표시합니다. 이 표현은 의학적 확률이나 인과관계가 아닙니다.

⚠️ 하루 배변하지 않았다고 변비인 것은 아닙니다. 원래 공통 가중치는 주 단위 섭취 빈도와 ‘변비 유무’ 데이터로 학습되었으나, 현재는 하루 섭취 유무와 ‘다음 날 배변 유무’를 사용합니다. 입력 정의와 정답이 모두 달라 초기 가중치의 타당성은 보장되지 않습니다. 모델의 “높이는/낮추는 방향” 표시는 실제 건강 위험을 증감시킨다는 뜻이 아닙니다. 학습률은 1로 고정되어 있으므로 입력값에 따라 가중치가 크게 바뀔 수 있습니다. 분류 정확도는 검증되지 않았습니다. 과거 입력 형식의 기록은 학습에서 제외하고, 재입력 후 저장한 날부터 새 기준으로 사용합니다. 의학적 진단·발생 확률이 아니며, 물 섭취량 1~2L 이외의 입력값은 원래 학습 범위를 벗어납니다.

날짜를 누르면 수정할 수 있어. 달력의 모델 판단은 해당 날짜보다 이전 기록만 학습한 가중치를 사용하며, 어제 배변 기록이 없으면 결과를 표시하지 않습니다.

이번 달 기록 요약

내 퍼셉트론 가중치

각 사용자마다 공통 가중치 [1.5, −6, 0, 1, −1, 0]에서 시작합니다. 입력 방식이 변경되어 기존 가중치의 예측 성능은 별도로 재검증해야 합니다. 날짜 D의 배변 유무를 정답으로, 전날(D-1)의 생활 습관을 입력값으로 시간순 학습합니다. 전날에 생활 습관 기록이 있고 다음 날 배변 여부가 입력되어야 한 쌍이 완성됩니다. 수정 또는 삭제하면 기존 기록을 기준으로 다시 계산해 중복 학습을 막습니다.

입력변수공통 가중치개인 가중치

학습 규칙: 기본 퍼셉트론 (학습률 1)
오분류 또는 경계에 있을 때 w ← w + y·x로 갱신합니다. 날짜 D의 실제 배변 여부는 날짜 D−1의 생활 습관으로 학습합니다. 사용자마다 서로 다른 가중치를 갖습니다.

학습률 1에서는 가중치 변화가 커질 수 있고, 개인별 기록이 적으면 불안정해질 수 있어. 가중치의 부호를 생활 습관의 원인이나 치료 지침으로 해석하지 마.

유산균 잔여량 · 96시간 시뮬레이션

교육용 수학 모델 · 실제 장내 생존균 수를 측정하거나 예측한 값이 아닙니다. 입력한 섭취 균수와 시각으로 계산한 가상 잔여량입니다. 복용 안전성이나 제품 효과의 근거로 사용하지 마세요.

CFU는 제품에 표시된 생균수 단위입니다. 제품 표시에 있는 숫자를 입력하세요. 단, 표시 균수가 실제 장내 전달량과 같다는 뜻은 아닙니다.

섭취 기록

아직 기록이 없습니다.

그래프 ① 한 번 섭취 후 0~12시간

선택한 섭취 기록 1건의 시간별 예상 잔여 균수입니다. 0~4시간과 4~12시간 구간의 식을 사용합니다.

그래프 ② 여러 번 섭취한 유산균의 예상 잔여량 합계

각 섭취 시점에 새로운 균수를 더하고, 이전 섭취분의 남은 양은 각각 96시간까지 감소시킨 뒤 합합니다. 12~96시간은 직선 감소하며, 섭취 96시간 후 해당 섭취분은 0입니다.

⚠️ 해당 그래프는 사용자 입력과 가정한 식으로 만든 수학적 시뮬레이션입니다. 실제 유산균 잔존 기간, 장 점막 정착, 변비 개선 효과를 보여주지 않습니다.
