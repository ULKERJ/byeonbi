개인 기록과 학습 가중치를 클라우드에 동기화

클라우드 연결 설정 필요

Firebase 연결 정보는 입력됐어. 이제 파일 안의 ADMIN_UID를 관리자 계정의 실제 UID로 바꾸고 HTTPS로 배포해 줘.

설정 방법은 함께 제공한 README 파일에 있어.

로그인

최초 관리자 계정은 Firebase에서 아이디 admin으로 생성해야 해. 아이디만으로 접속하는 방식은 개인정보 보호에 적합하지 않아 비밀번호를 추가했어.

일별 생활 습관 입력

변비 여부는 하루 배변 유무만으로 판단하지 않아. 실제 변비 상태는 사용자가 스스로 기록하는 참고 항목이며, 이 프로그램은 진단·발생 확률 계산·약물 변경 지시를 하지 않아.

기록이 있는 날짜를 누르면 입력 화면에서 수정할 수 있어.

이번 달 기록 요약

내 퍼셉트론 가중치

공통 가중치에서 시작해 실제 변비 상태가 입력된 날짜를 시간순으로 재학습해. 잘못 입력한 기록을 수정해도 처음부터 다시 계산하므로 중복 학습되지 않아.

입력변수공통 가중치개인 가중치

개인별 기록이 적으면 가중치가 불안정해질 수 있어. 가중치의 부호를 생활 습관의 원인이나 치료 지침으로 해석하지 마.

사용자 계정 추가

등록된 사용자

관리자는 새 계정을 만들 수 있지만 사용자의 건강 기록을 자동으로 열람하지 않아. Firebase Authentication에서 최초 관리자 계정을 만들고 보안 규칙을 적용해야 해.
